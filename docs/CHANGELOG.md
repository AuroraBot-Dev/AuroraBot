# 变更记录

## 未发布

- Playground 提取公共独立工作台声明，统一实例创建、操作绑定、资源释放、重置和版本化检查点复现；Agent 与 Kernel 改为声明配置、装配与业务操作，不再维护专属 Session 和记录循环。只有隔离装配中明确允许的操作才能复现，整条序列在装配前校验。
- Kernel Playground 支持选择模块组合、注入自定义 namespace、通用同步/异步调用、实际路由观察和多实例；资源准备与释放复用 Host 生命周期，重置配置统一通过 `configuration` 指定。

- Agent Playground 增加独立工作台，可用 JSON 配置模型响应、工具 schema 与回执、行动前策略和执行上限，或通过 Python 注入真实端口；支持实际模型请求检查、无正文端口轨迹、独立重置、显式导出与离线逐检查点复现，并提供独立文件入口。真实依赖不自动重放。

- Playground 增加 `/` 命令及自动补全：行终端输入时显示带说明的候选，支持模块、操作和命令参数补全、方向键选择、Tab / Enter 确认与 Esc 取消；TUI 支持 `/` 或 Ctrl+P 打开命令面板，并可用 Enter 提交斜杠命令。

- Playground 改为紧凑深色界面、可搜索模态选择器与 JSON 语法高亮；默认缩进输出，`--no-pretty` 关闭高亮与缩进，行终端启动提示收为名称。CLI 支持直接输入真实 `aurora` 命令，通过独立进程读取项目配置与插件，返回退出码和输出，支持预设标准输入与超时；演示命令显式使用 `cli.demo`。

- Bot 认知改为通过命名 hook 连接独立 `aurora_agent.Run`，移除 AgentTree、节点与内建委派；模块装配不再以 Python 契约类型作为服务键。
- 世界事实、运行索引、实例资源、记忆曝光及节律／时钟恢复统一使用 `run_id`；增加并发运行身份争用、证据归属和取消期间结果提交的校验。
- 运行配置使用 `[engine.run]` 的模型次数、工具次数与上下文字符上限；Agent 配置移除 `children`，工具 `world_runs` 提供运行索引，同步更新默认提示词和离线 ReAct 示例。
- 增加自动发现的 `aurora playground` 命令，直接透传参数并保留终端和 JSON 管道输出，支持用顶层 `--root` 指定源码仓库；纯透传命令的帮助参数由目标程序处理。
- Playground 增加 `--tui` Textual 界面，支持模块与操作选择、参数 JSON 编辑、示例载入、接口说明和格式化结果；串行调用保留会话状态，退出时清理异步资源。
- Playground 支持 `--pretty` 缩进输出、`--module` 预选模块和简写命令；终端增加内存历史、Tab 补全和多行 JSON 输入，管道默认保持 JSON Lines 输出。
- Playground 增加自动发现的 Agent JSON 交互模块，支持按运行身份创建、逐步执行、追加输入、连续执行、快照与取消；会话按需复用事件循环并在退出时清理，预设场景与交互入口共用离线替身。
- Playground 按模块子包自动发现 `MODULE`，会话按需绑定独立操作；交互适配与预设场景分开组织，场景入口统一为 `python -m playground.examples.<名称>`。
- 增加独立 Agent 离线 playground，展示 ReAct 循环、工具和模型执行期间追加消息、协作式取消、行动前重新判断与未知效果停止。
- 增加 `uv run python -m playground` 终端 JSON 交互入口，提供 Kernel 与 CLI 黑盒调用、输入输出 schema、可执行示例、状态重置和结构化错误响应。
- 新增独立的 `aurora_agent` ReAct 核心，支持逐步或连续执行、安全边界消息追加、事件订阅、不可变快照、行动前策略、运行限制与取消；工具效果未知时保留状态并停止，不自动重放。
- 重整认知执行器，将推理装配、循环推进、工具与委派执行及世界效果分离；ReAct 调用点复用共享 kernel 路由，增加离线自定义推理 playground。
- Bot 模块支持调用点和实现声明并归档到模块清单；能力视图统一读取 ctx，移除重复状态副本，通用调用路由冻结为可检查的只读计划。
- 不可见工具在 scope 解析之前拒绝，异步可调用对象在同步路由产生效果前拒绝；补充自定义推理、并发请求、未知效果与插件发现的验证。
- 整理文档站，聚焦操作指引、稳定概念与使用限制，删减内部实现和测试索引；在 `AGENTS.md` 与文档贡献规范中明确仅随用户使用变化更新文档站，未确定内容标记为“文档待编写”。
- 为 `aurora_kernel` 增加包内 README，说明通用 hook 与 Bot 认知执行的边界、模块声明、共享上下文、生命周期和发现方式。
- 增加 `playground/kernel_playground.py`，可运行通用内核的 hook、共享上下文、事务冲突、生命周期与装配校验场景。
- CLI 参数解析与命令分派分离；各层长选项统一要求完整名称，多层子命令显示当前层级帮助。
- `app` 的参数规格、入口分派与安装交互分离，三种安装来源共用计划确认、取消和结果展示流程。
- 配置装配在调用解析器前检查全部重复声明，配置目录加载避免重复查找配置项。
- 增加 `playground/cli_playground.py`，提供离线运行的命令分派、插件发现、配置管理与声明校验场景，并在 CLI 包内 README 中说明用法。
- 内置命令统一收纳为 `aurora_cli/commands/<name>/` 包，由包入口导出 `MODULE`。
- 内置命令与配置统一导出 CLI 插件声明，与 `extensions/cli/` 和 `aurora_cli_plugin` 安装入口共用发现、依赖及冲突校验；配置查看、编辑、模板初始化和启动使用同一次加载的目录，移除全局命令目录和配置缓存。
- Python 发行包名设为 `aurorabot-ai`，补充项目链接，并同步 CLI 的安装版本查询。
- 配置模板与解析器按配置项收归 `aurora_cli/configs/`，启动时只补齐缺失文件；setup 按项询问是否创建，默认跳过。`.env` 新建默认同意，重置已有文件默认拒绝。
- 初始化脚本统一使用工程任务的 Clack 交互样式，支持方向键选择与 Ctrl+C 取消。
- 项目初始化与可选全局链接统一到无第三方依赖的 `scripts/setup.ts`；`aurora setup` 和各平台启动脚本共用该入口，可直接运行 `node scripts/setup.ts` 或 `pnpm run setup`。
- 工程脚本统一使用 `.ts` 扩展名，文档站任务目标统一命名为 `docsite`。
- 安装脚本固定使用 UTF-8；Windows 脚本使用 UTF-8 BOM，并设置控制台、管道及 Python 子进程编码。
- 精简文档站的历史叙述、重复说明和未实现能力描述，修正文档入口与贡献流程；RFC 和工具路径草案移至 `docs/rfc/`。
