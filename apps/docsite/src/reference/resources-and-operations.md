# 资源与操作

资源名用于在配置和终端中准确指定模型、工具、查询等对象。本页说明如何查找和使用它们。

## 查找与查看

启动 Bot 后，在交互终端输入：

```text
/resources
/resources --namespace aurora --kind query
```

复制结果中的资源名，用 `/inspect 资源名` 查看说明。可用筛选项和命令用法见 `/help`。

## 读懂资源名与版本

资源名的形式为 `namespace:domain/kind/path`，分别表示命名空间、领域、类别和具体名称。例如 `aurora:memory/model/tgn` 表示一个记忆模型。

`资源名@版本` 指向确定版本。未指定版本时，需要能够解析到唯一版本或明确别名；存在歧义会报错。更改别名不会改写已经保存的历史引用。

内容资源可能使用完整 SHA256 作为版本；请复制查询结果或训练报告中的引用，不要自行猜测版本。

## 调用操作

先查看操作说明和参数要求，再使用：

```text
/call 资源名@版本 {"参数名":"参数值"}
```

这是语法示意，需要替换为实际操作和参数。查询用于读取信息，命令可能修改状态或产生外部效果。终端调用直接执行指定操作，不会让 Bot 先思考是否需要执行。

## 结果与恢复

操作结果区分 `succeeded`、`failed` 和 `unknown`，具体含义见[认知与恢复](../architecture/runtime-core#如何理解行动结果)。

收到请求不代表行动完成；超时或断线也不代表没有发生效果。遇到 `unknown` 时，先核对外部状态，再决定后续操作。手动重复输入命令不能视为对同一请求的安全恢复。

大结果可能显示内容引用，需要进一步读取正文；看到引用本身不等于已经核对其中的证据。运行记录中的 `started` 只说明有开始记录，不能证明任务此刻仍在执行。
