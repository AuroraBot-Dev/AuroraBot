# 验证改动

在仓库根目录执行与改动范围对应的检查。

## Python

```bash
uv sync --locked --group dev
uv run aurora check --fix
```

检查包含代码规范、格式、类型检查和测试。自动修复后请复核差异。

## 前端与文档

```bash
pnpm check apps
```

该命令检查前端类型、代码规范与测试，并构建应用。只修改文档时，可先运行 `pnpm build docsite` 验证页面构建与内部链接。

## 验证重点

根据用户可观察的变化选择验证场景：

- 安装、启动、配置修改和命令是否可用。
- 目标、经历与安排是否能在重启后继续使用。
- 行动结果是否准确区分成功、失败和未知，是否避免重复效果。
- 权限、读取范围和历史时间边界是否得到遵守。

测试应离线、确定且可重复，使用替身代替外部模型和服务。通过自动检查不代表模型在真实任务中一定有收益；策略效果还需在相同任务与预算下比较，见[节律与记忆](./learning#如何判断是否有帮助)。

具体代码约束见仓库根目录 `AGENTS.md`，贡献步骤见[开发](../develop/)。
