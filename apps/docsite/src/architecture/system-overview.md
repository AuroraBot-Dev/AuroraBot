# 系统总览

AuroraBot 为长期存在的 Bot 提供人格、目标、记忆和行动环境。一次对话或思考结束，不代表她的目标结束；已保存的经历和安排可以在重启后继续使用。

## Bot 如何与世界交互

消息、应用通知和工具结果先成为世界事件。Bot 结合目标与记忆理解这些事件，再决定回应、行动、安排后续检查或等待。

模型负责理解与判断；发送消息、访问外部服务等实际行动通过工具完成，执行结果再回到世界。终端显示的文字只是本地输出，不代表消息已发送到外部平台。

## 几个基本概念

| 概念 | 对使用者的意义                                          |
| ---- | ------------------------------------------------------- |
| 世界 | Bot 已经获知的事件与行动结果，是回看经历的依据          |
| 目标 | Bot 希望持续推进的事项，可以修订、完成或放弃            |
| 记忆 | 帮助 Bot 理解当前问题的过往经历，不保证每次载入全部历史 |
| 节律 | 决定何时获得思考机会，不替 Bot 决定具体行动             |
| 工具 | Bot 可以使用的行动能力，受配置的可见范围限制            |
| 应用 | 提供外部工具和事件的连接，例如社交平台或桌面服务        |
