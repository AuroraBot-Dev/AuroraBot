# 认知与恢复

## 一次思考与长期目标

Bot 可以围绕当前事件进行思考、调用工具或委派任务。一次执行结束，只表示这一轮处理结束，不等于长期目标已经完成。

目标、已确认进展和未来安排可以持久保存。Bot 也可以选择等待，而不是对每一条输入立即采取行动。

## 重启之后

重启后，Bot 可以读取已保存的状态和经历，处理到期安排；进程停止期间不会执行行动。

恢复不代表从中断的模型输出或工具调用处原样续跑。已确认完成的行动不会因恢复再次执行；可能已经产生外部效果、但尚未确认结果的行动需要先核对实际状态。

## 如何理解行动结果

| 状态        | 含义                         | 后续处理                     |
| ----------- | ---------------------------- | ---------------------------- |
| `succeeded` | 已确认成功                   | 依据结果继续                 |
| `failed`    | 明确拒绝，或已确认未产生效果 | 根据原因修正输入或环境       |
| `unknown`   | 可能已经产生效果，但无法确认 | 先检查外部状态，避免重复行动 |

超时或断线并不总意味着失败。例如发送消息后失去连接，消息可能已经送达。未知效果的非幂等操作不会自动重放。

## 记忆与上下文限制

Bot 每次思考能读取的内容有限，并不等于拥有全部历史对话。记忆会选择与当前问题相关的经历，必要时可通过工具查看原始来源。

必要约束、恢复状态或证据超出上下文容量时，本次执行会报错，不会通过丢弃这些内容继续行动。历史查询以当时已获知的信息为界，不把后续反馈当作过去已经知道的事实。

节律与记忆策略的选择见[节律与记忆](./learning)。数据保存位置见[配置与存储](./configs)。
