# MCP 应用接入

MCP App 为 Bot 提供外部工具和业务事件，具体平台能力由 App 决定。

## 配置连接

1. 安装目标 App，并按它的说明准备运行环境和凭据。
2. 执行 `aurora config apps --init` 创建配置，再用 `aurora config apps --edit` 编辑。
3. 找到或添加对应 App，填写连接信息并设置 `enabled = true`。
4. 执行 `aurora config --check`，重启 Bot。

内置配置包含未启用的 App 示例；创建配置不会自动安装或启动这些应用。

| 连接方式              | 需要填写                                   | 限制                          |
| --------------------- | ------------------------------------------ | ----------------------------- |
| 本地 `stdio`          | 工作目录、启动命令和 `env` 环境变量白名单  | App 的标准输出用于 MCP 通信   |
| HTTPS Streamable HTTP | 服务 URL，必要时填写 `auth_env` 凭据变量名 | 只支持 HTTPS，不支持 HTTP+SSE |

工具发现后，还需通过 `agents.toml` 的 `tools` 或工具标签使相应 Agent 可见。接入 App 不代表所有 Agent 都能使用其全部工具。

## 接收业务事件

`apps.toml` 中的 `event_mode` 决定是否接收应用事件：

| 值                    | 用途                                                      |
| --------------------- | --------------------------------------------------------- |
| `disabled`            | 禁用业务事件，默认值                                      |
| `world_events`        | 使用 AuroraBot 世界事件扩展，仅支持 stdio，需 App 支持    |
| `legacy_aurora_event` | 接收约定格式的 `aurora/event` 通知，仅适用于握手式 Server |

事件进入世界后，由 Bot 判断何时处理以及是否行动，不保证收到通知就立即回复。事件没有确认或重放保证，断线丢失的通知不会自动补发。

## 运行限制

- 启用的 App 连接或工具发现失败会阻止启动，请核对 App 运行环境、凭据和连接配置。
- 工具目录在启动时加载，运行期间发生变化需要重启。
- 连接断开不自动重连，工具效果不自动重试；无法确认结果时按 `unknown` 处理，见[认知与恢复](./runtime-core)。
- 当前工具结果以文本或结构化内容呈现，不支持图像、音频等非文本结果。
