# 贡献与修订文档

页面位于 `apps/docsite/src/`，按读者任务组织：

- `start/`：安装、启动与日常配置。
- `develop/`：贡献流程、公开扩展用法与验证入口。
- `architecture/`：理解产品所需的稳定概念、能力与使用限制。
- `reference/`：用户可查阅的命名、操作结果和常见问题。

## 内容取舍

正文以简体中文描述当前用法、能力和限制。优先回答“如何使用”“会得到什么结果”和“有哪些限制”，只保留完成读者任务所需的原理与示例。

- 内部重构、文件移动、类名调整或算法替换，原则上不要求修改文档站。
- 安装、配置、命令、交互流程、公开扩展用法或使用结果改变时，更新受影响的页面。
- 源码目录表、内部类型和字段清单、逐步执行流程及测试文件索引放在源码注释、包内 README 或测试中。
- 尚不便确定或未经核实的部分写“文档待编写”，不根据设想补齐教程、接口或能力承诺。
- 变更经过和修复记录写入仓库的 `docs/CHANGELOG.md`；未实施草案不进入文档站。

同一内容通过链接引用，避免重复。审阅时可以自问：如果实现替换但用法和结果不变，这段说明是否仍然成立？

## 页面与验证

标题说明页面主题，`order` 控制侧边栏排序。站内链接使用相对路径；命令示例注明执行目录，并与实际入口一致。

在仓库根目录预览和验证：

```bash
pnpm dev docsite
pnpm build docsite
```

构建检查 Markdown 和站内链接。完整环境说明见[离线文档](../start/offline-docsite)。
