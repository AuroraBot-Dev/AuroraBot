只输出一个 JSON 对象。第一个字符是 `{`，最后一个字符是 `}`。除此之外不要输出任何文字。

## 场景

$$scene$$

## 命令（复制 JSON 填入值）

$$commands$$

## 格式

```json
{"thought": "判断和理由", "actions": []}
```

- `thought`：分析
- `actions`：命令数组。发三句话就放三个 send。发消息同时设闹钟就两者都放
- 不做任何事：`"actions": []`
- 命令对象：`{"command": "命令名", "params": {参数: 值}}`
- 命令名从上面「命令」里照抄
