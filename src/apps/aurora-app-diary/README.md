# 日记 (aurora-app-diary)

**包名**: `im.polaris.diary`

**版本**: 1.1.0

**最低 Brain 版本**: >=5.0.0

负责日记的持久化存储和检索。写入时接受任意内容文本并按日期保存, 读取时可以按日期查询或列出所有已记录的日期。

---

## 指令

### `write_diary` -- 写入日记

将内容写入指定日期的日记文件。

| 参数      | 类型   | 必填 | 说明                  |
| --------- | ------ | ---- | --------------------- |
| `date`    | string | 是   | 日期, 格式 YYYY-MM-DD |
| `content` | string | 是   | 日记内容              |

| 返回字段 | 类型    | 说明         |
| -------- | ------- | ------------ |
| `saved`  | boolean | 是否保存成功 |
| `date`   | string  | 写入的日期   |

### `read_diary` -- 读取日记

读取指定日期的日记内容。

| 参数   | 类型   | 必填 | 说明                  |
| ------ | ------ | ---- | --------------------- |
| `date` | string | 是   | 日期, 格式 YYYY-MM-DD |

| 返回字段  | 类型    | 说明           |
| --------- | ------- | -------------- |
| `found`   | boolean | 当天是否有日记 |
| `date`    | string  | 查询的日期     |
| `content` | string  | 日记全文       |

### `list_dates` -- 列出已有日记日期

列出所有已有日记的日期列表。

无参数。

| 返回字段 | 类型   | 说明       |
| -------- | ------ | ---------- |
| `dates`  | array  | 日期列表   |
| `count`  | number | 日记总天数 |

---

## 使用

在 `legacy/config.yml` 的 `apps` 节点下添加或启用 `diary`:

```yaml
apps:
  diary:
    enabled: true
    startup: {}
  # //其他应用//
```

- `enabled: true` -- 启用该应用
- `startup: {}` -- 启动参数, 日记应用无需额外启动配置
